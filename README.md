1. Download Warp Terminal from (https://www.warp.dev/)
2. Create relevant folders `mkdir -p ~/.vim ~/.vim/autoload ~/.vim/backup ~/.vim/colors ~/.vim/plugged`
3. Install `Vundle` to allow PluginInstall in Vim (https://github.com/VundleVim/Vundle.vim)
4. Move over the vim setting from this github to `~/.vimrc` and install all the plugins using `:PluginInstall`
